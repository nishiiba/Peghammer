

# 手作業ではんだ付けを行う場合

パーツの取付を自分で行う場合の組立方法です  
PCBAより安く作れますが簡単ではありません  
この方法を選ぶ方は電子工作に慣れているかと思うので要点のみ説明しています

## はんだ付け



### 各部品の取り付け方法と注意

**■FFCコネクタ**  
少し多めのはんだペーストを使ってリフローを行い  
ブリッジした余計なはんだを吸い取り線で調整する方法が確実です  
うまくはんだ出来ているかはスマホのマクロ撮影を使うと確認しやすいです  

<br>

**■5方向スイッチ**  
はんだペーストとはんだごてを使用します

①両側のアースをはんだづけ  
②ピンセットで金属カバーを軽く押さえながらアースのはんだを片側ずつ溶かし基板に密着させる  
③端子をすべてはんだづけ  

②を行わないと金属カバーが浮いてスティックがゆるゆるになります　

はんだペーストが多過ぎると接触､動作不良を起こすので最低限の量を塗布して下さい  
取り付け終わったらフラックスクリーナーでスイッチの回りを洗浄します  

<br>

**■タクトスイッチ**  
はんだペーストを使用してリフローを行います  
ペーストが多過ぎると接触､動作不良を起こすので最低限の量を塗布して下さい  
スイッチは白枠からずれているとキャップがはまらなかったりスムーズに動かない場合があります  






<br><br>

## はんだ付け手順


### ①メイン基板  
マイコンのスルーホールをマスキングしてから  
5方向スイッチ　→　ロータリーエンコーダ　→　タクトスイッチ　の順ではんだ付け

<br>

### ②トリガー基板  
FFCコネクタ　→　タクトスイッチ　の順ではんだ付け

<br>

### ③電池基板  

FFCコネクタ　→　スライドスイッチ　→　バッテリーホルダクリップ　の順ではんだ付け　

バッテリーホルダクリップはPCBAと部品が違うので  
マイナス側のクリップを1mmほど内側にずらしてはんだ付けを行って下さい
